Grainflow

When US corn crop ratings fall, does corn rise the next week?

A streaming lakehouse that joins CBOT futures, NOAA weather and USDA crop ratings, then answers that question with nine seasons of data. Yes, modestly: corn gained about 0.9% the week after ratings fell, and the gap is statistically significant.

What it shows

  • Contracts as code. One YAML per dataset drives validation, schemas, tests and freshness alerts.
  • A real bug caught in the model. Equal-weighting 41 states diluted the signal; the mart now uses USDA's 18.
  • Production fixes. A Spark out-of-memory on a 10-year backfill, solved by switching Iceberg to clustered writes.
  • Runs for free. The same dbt models rebuild on DuckDB four times a day on Vercel.

Silo

Ask Grainflow's data a question in plain English and get the numbers, with the SQL behind them.

An MCP server and an AI analyst over Grainflow's gold tables. Any MCP client can use the same tools. It can only read, it shows its work, and 13 graded questions gate every change.

  • Anthropic API

What it shows

  • Guardrails that hold. A parser allows one read-only SELECT, and the engine itself can't touch files or the network.
  • Evals against live data. Expected answers are computed by SQL at test time; the first run caught a wrong ranking.
  • A semantic layer. Named metrics carry analyst rules, like never averaging corn with soybeans.
  • Bounded cost. About a tenth of a cent per answer, a daily budget, and per-visitor limits.

Orderline

Will this order arrive late?

A shop's Postgres database is captured change by change with Debezium and rebuilt in Databricks: inserts, updates and deletes, with customer history kept. A model predicts which open orders will miss their promise date, and because the causes of lateness were planted, it's checked against the truth, not just a score. AUC about 0.90, against 0.67 from carrier late rates alone.

  • Postgres
  • Debezium

Open the page Code

What it shows

  • Change data capture done safely. The replication slot only moves after a batch is in Databricks, so a failed sync loses nothing. CI replays every captured event and checks it rebuilds the source tables row for row.
  • CDC that respects order. Silver applies changes by log position, not timestamps, and gold joins each order to the customer as they were at checkout, even when the source clock went backwards once.
  • Honest labels. Orders that haven't reached their promise date are unknown, not on time, and aren't scored once they're overdue.
  • Champion and challenger. Weekly retraining in MLflow; a new model is promoted only if it gets the causes right and beats the champion on the same recent orders.

How I work

The same habits run through all three.

Trust the data first

Contracts, tests and quarantine tables before dashboards. A number nobody can check isn't an answer.

Measure the AI

Models get the same treatment as pipelines: guardrails, traces, and evals that fail a PR when accuracy drops.

Ship it small

Every change is a reviewed PR with green CI. Everything here runs live on free or near-free infrastructure.
