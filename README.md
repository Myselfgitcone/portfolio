# jagadish-butukuri.vercel.app

My portfolio: one page, built by hand, no framework.

The status board at the top and the live line under each project read the
projects' own published data when the page opens, so the numbers are whatever
the systems say right now:

| Project | Feed |
| --- | --- |
| [Orderline](https://github.com/Myselfgitcone/orderline) | `myselfgitcone.github.io/orderline/data/site.json` |
| [Grainflow](https://github.com/Myselfgitcone/grainflow) | `grainflow-mauve.vercel.app/data/lake/manifest.json` |
| [Footnote](https://github.com/Myselfgitcone/footnote) | `myselfgitcone.github.io/footnote/status.json` |

Vercel deploys `main`. Open `index.html` in a browser to preview locally.
